HOW TO PUBLISH SKILLEAZE (GitHub Pages)

STEP 1: Download "Skilleaze website" (the website folder). Copy EVERYTHING inside it into the root of your repo (replace existing files). This contains the main site, blog, policies, sitemaps, robots.txt, llms.txt, assets, scripts and all city hub pages.

STEP 2: Download "Skilleaze SEO page zips". Unzip, into the SAME repo root, in this order, choosing Replace each time:
  a) keyword-pages-01 ... keyword-pages-15
  b) service-pages-01 ... service-pages-04

STEP 3: Push with GitHub Desktop or git (the GitHub website only accepts 100 files per upload).

STEP 4: Google Search Console + Bing Webmaster Tools: submit https://www.skilleaze.com/sitemap-index.xml

STEP 5: Bing IndexNow ping after each push:
https://www.bing.com/indexnow?url=https://www.skilleaze.com/&key=9f3c2a7e5b1d4c8fa6e0b2d7c4a19e53

See SEO-TODO.md for off-page tasks.
